## 🎯 Project Overview
**Naku Coffee** is an interactive web platform designed to elevate the home-brewing experience for specialty coffee enthusiasts. Combining editorial brand storytelling with hands-on brewing utilities, the interface guides users through brew ratios, grind sizes, and timers while allowing them to track tasting notes and shop specialty beans.

## ✨ Key Interactive Flows & Features
* **Multi-Method Brewing Guide:** Interactive workflows for **Pour Over**, **French Press**, **Moka Pot**, and **Cold Brew**, featuring dedicated grind-size selectors, brew-ratio calculators, and step-by-step timers.
* **Interactive Coffee Journal (CRUD Prototype):** Full state-based prototyping allowing users to log new brews (`+ New Entry` modal), rate extractions, edit tasting notes, delete entries, and view summary metrics (*Total Brews*, *Average Rating*, *Favorite Ratio*).
* **Specialty Coffee Storefront:** Structured e-commerce views organized across *Coffee Beans*, *Brewing Equipment*, and *Merchandise*, paired with brand storytelling (*About Us* & *Brand Values*).
